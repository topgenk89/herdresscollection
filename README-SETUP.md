# TERRA Rental — Panduan Setup

Website sewa dress dengan pemesanan lewat **WhatsApp** dan panel admin
(tambah/hapus produk + upload gambar) yang tersimpan permanen di **Supabase**.

---

## 1. Coba dulu tanpa setup (mode demo)

Buka `index.html` langsung di browser. Situs sudah berjalan memakai **data contoh**.
Kamu bisa menjelajah, menambah ke keranjang sewa, dan mengetes tombol WhatsApp.

> Di mode demo, produk yang kamu tambah di halaman **admin.html** TIDAK tersimpan permanen.
> Untuk penyimpanan permanen yang terlihat semua pengunjung, ikuti langkah Supabase di bawah.

---

## 2. Ganti nomor WhatsApp

Buka **`js/supabase-config.js`**, ubah baris:

```js
const WHATSAPP_NUMBER = "6281234567890";
```

Gunakan format internasional tanpa `+`, spasi, atau `0` di depan.
Contoh nomor `0812-3456-7890` → ditulis `6281234567890`.

> Ada juga link WhatsApp di beberapa tombol/footer HTML (dicari `6281234567890`)
> yang bisa kamu ganti bila perlu.

## 3. Setup Supabase (penyimpanan permanen — GRATIS)

### a. Buat project
1. Daftar/masuk di <https://supabase.com> (gratis).
2. Klik **New Project**, beri nama (mis. `terra-rental`), atur password database, pilih region terdekat (Singapore), lalu **Create**.

### b. Buat Tabel (Produk, Pesanan, Pengaturan)
Buka menu **SQL Editor** → **New query**, tempel SQL berikut, klik **Run**:

```sql
-- 1. Tabel Produk
create table products (
  id         bigint generated by default as identity primary key,
  name       text not null,
  brand      text default 'TERRA Rental',
  price      numeric not null,
  was        numeric,
  cat        text default 'pesta',
  badge      text,
  sizes      text[] default '{"S","M","L","XL"}',
  status     text default 'tersedia',
  img        text,
  alt        text,
  created_at timestamp with time zone default now()
);

-- 2. Tabel Catatan Sewa
create table orders (
  id               bigint generated by default as identity primary key,
  customer         text not null,
  customer_phone   text,
  dress_name       text not null,
  rent_start       date not null,
  rent_end         date not null,
  status           text default 'berjalan',
  created_at       timestamp with time zone default now()
);

-- 3. Tabel Pengaturan
create table settings (
  id           text primary key,
  value        text not null
);

-- Isi Pengaturan Awal
insert into settings (id, value) values 
('topbar_text', 'Sewa dress mulai Rp175.000/hari · Pesan langsung via WhatsApp'),
('wa_number', '6281234567890');

-- Aktifkan akses publik terbatas & keamanan RLS
alter table products enable row level security;
alter table orders enable row level security;
alter table settings enable row level security;

-- Produk & Setting: Semua orang boleh BACA, tapi HANYA ADMIN yang boleh TAMBAH/UBAH/HAPUS
create policy "Baca produk" on products for select using (true);
create policy "Kelola produk (Admin)" on products for all using (auth.role() = 'authenticated');

create policy "Baca setting" on settings for select using (true);
create policy "Kelola setting (Admin)" on settings for all using (auth.role() = 'authenticated');

-- Orders: Pengunjung (publik) HANYA BISA MENAMBAH (saat checkout), ADMIN bisa BACA/UBAH/HAPUS
create policy "Pelanggan bisa buat order" on orders for insert with check (true);
create policy "Kelola order (Admin)" on orders for select, update, delete using (auth.role() = 'authenticated');
```

> **Keamanan Terjamin (RLS):** Dengan kode di atas, tidak ada orang iseng yang bisa menghapus dress Anda dari luar. Hak untuk menambah/menghapus/mengedit produk HANYA diberikan kepada user yang sudah login (`authenticated`).

### b2. Tambahan: Tabel Kategori & Koleksi (Wajib untuk fitur menu dinamis)
Agar kategori (Gaun Pesta, Kebaya, dll) dan Koleksi tematik (Koleksi Lebaran, Wisuda, dll) bisa dikelola dari panel admin, jalankan SQL berikut di **SQL Editor** (aman dijalankan walau tabel produk sudah ada):

```sql
-- Tabel Kategori
create table if not exists categories (
  id         bigint generated by default as identity primary key,
  slug       text unique not null,
  name       text not null,
  ord        int default 0,
  created_at timestamp with time zone default now()
);

-- Tabel Koleksi Tematik
create table if not exists collections (
  id          bigint generated by default as identity primary key,
  slug        text unique not null,
  name        text not null,
  description text,
  img         text,
  ord         int default 0,
  created_at  timestamp with time zone default now()
);

-- Tambah kolom 'collection' di tabel produk (menautkan produk ke koleksi tematik)
alter table products add column if not exists collection text;

-- Isi kategori awal
insert into categories (slug, name, ord) values
  ('pesta', 'Gaun Pesta', 1),
  ('kebaya', 'Kebaya', 2),
  ('bridesmaid', 'Bridesmaid', 3),
  ('pengantin', 'Pengantin', 4)
on conflict (slug) do nothing;

-- Isi contoh koleksi tematik
insert into collections (slug, name, description, ord) values
  ('lebaran', 'Koleksi Lebaran', 'Busana muslim & kebaya untuk Idul Fitri', 1),
  ('wisuda', 'Koleksi Wisuda', 'Gaun elegan untuk hari kelulusanmu', 2)
on conflict (slug) do nothing;

-- Keamanan (RLS): publik boleh baca, admin boleh kelola
alter table categories enable row level security;
alter table collections enable row level security;

create policy "Baca kategori" on categories for select using (true);
create policy "Kelola kategori (Admin)" on categories for all using (auth.role() = 'authenticated');

create policy "Baca koleksi" on collections for select using (true);
create policy "Kelola koleksi (Admin)" on collections for all using (auth.role() = 'authenticated');
```

### c. Buat bucket gambar (Storage)
1. Buka menu **Storage** → **Create a new bucket**.
2. Nama bucket: **`product-images`** (harus sama persis).
3. Centang **Public bucket** → **Create**.

Lalu beri izin upload. Di **SQL Editor**, jalankan:

```sql
create policy "Boleh baca gambar" 
  on storage.objects for select using (bucket_id = 'product-images');

create policy "Hanya admin boleh upload" 
  on storage.objects for insert with check (bucket_id = 'product-images' and auth.role() = 'authenticated');

create policy "Hanya admin boleh hapus" 
  on storage.objects for delete using (bucket_id = 'product-images' and auth.role() = 'authenticated');
```

## 4. Cara Membuat Akun Admin (Email & Password)
Karena keamanan sudah diperbarui, Anda tidak bisa lagi menggunakan username "siawegg". Anda harus mendaftarkan email Anda sendiri sebagai Admin Utama.

1. Buka dashboard Supabase.
2. Perhatikan menu di sebelah kiri, klik **Authentication** (ikon dua orang).
3. Di dalam menu Auth, cari menu dropdown **Users**.
4. Klik tombol hijau **Add User** → pilih **Create New User**.
5. Masukkan **Email** Anda dan buat **Password** admin Anda.
6. Hapus centang pada *Auto Confirm User* (centang bagian ini agar aktif otomatis).
7. Selesai!

Sekarang buka `admin.html` di browser web Anda, dan masuklah menggunakan Email dan Password yang baru saja Anda buat di atas.

---

## 5. Cara pakai

- **Tambah produk:** buka `admin.html` → isi form + pilih foto → **Simpan Produk**.
- **Hapus produk:** di `admin.html`, klik **Hapus** pada item.
- **Pelanggan menyewa:** pilih dress → ukuran → **Tambah ke Keranjang Sewa** →
  isi nama, tanggal mulai & durasi → **Pesan via WhatsApp**. Pesanan otomatis
  terbuka di WhatsApp berisi rincian dress, ukuran, tanggal, dan estimasi total.
